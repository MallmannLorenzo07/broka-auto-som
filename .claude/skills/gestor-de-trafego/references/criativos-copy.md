## 1. Pesquisa antes de criar

Bons criativos saem de pesquisa, não de inspiração. Antes de escrever, levante (ou peça ao usuário):
- **Avatar:** quem compra, o que essa pessoa quer, do que tem medo, o que já tentou.
- **Dores e desejos** nas palavras do cliente: avaliações (do próprio produto e de concorrentes), comentários dos anúncios, Reclame Aqui, grupos, perguntas frequentes no WhatsApp/Direct.
- **Objeções:** preço, confiança, prazo, "funciona para mim?", "é difícil de usar?".
- **Diferenciais reais e provas:** números, depoimentos, garantia, tempo de mercado, mídia, certificações.
- **Concorrência:** Biblioteca de Anúncios do Meta (anúncios ativos há muito tempo = provavelmente lucrativos), TikTok Creative Center, Google Ads Transparency Center.
- **Estágio de consciência** (Eugene Schwartz): inconsciente → consciente do problema → consciente da solução → consciente do produto → mais consciente. Público frio precisa de mais contexto; remarketing pode ir direto à oferta.

## 2. Ângulos

Ângulo = **a razão principal pela qual alguém deveria se importar**. Cada ângulo é um conceito diferente (e encontra pessoas diferentes no algoritmo). Lista para gerar variedade:

| Ângulo | Exemplo (produto: fone com cancelamento de ruído) |
|---|---|
| Dor/problema | "Não consegue se concentrar no home office com o barulho do vizinho?" |
| Desejo/resultado | "Silêncio total em 1 segundo." |
| Prova social | "+12 mil avaliações 5 estrelas." |
| Autoridade/especialista | "Engenheiro de som testa 5 fones: o resultado surpreendeu." |
| Comparação/inimigo comum | "Por que pagar R$ 2.000 num fone de marca?" |
| Objeção quebrada | "Achei que era caro até fazer a conta por hora de uso." |
| Novidade/mecanismo | "A tecnologia que lê o ruído 50 mil vezes por segundo." |
| Urgência/escassez (real) | "Último lote com o preço de lançamento." |
| Identidade/estilo de vida | "Para quem trabalha viajando." |
| Uso/demonstração | "Testei no metrô na hora do rush." |
| Antes/depois (cuidado com a política) | Situação sem → com o produto. |
| Medo de perder (FOMO)/custo de não agir | "Quanto custa uma noite mal dormida?" |
| Presente/ocasião | "O presente de Dia dos Pais que ele vai usar todo dia." |
| Contraintuitivo | "Pare de comprar fone com mais graves." |

**Persona × ângulo:** combine personas diferentes (ex.: estudante, motorista de app, mãe que trabalha em casa) com ângulos. Isso gera diversidade real de criativos.

## 3. Hooks

O hook decide se o resto será visto. Combine **visual + texto na tela + fala**.

**Fórmulas de hook (adapte ao nicho):**
- Pergunta de dor: "Você também [problema específico]?"
- Afirmação polêmica: "[Crença comum] está errado."
- Resultado específico: "Como [persona] conseguiu [resultado] em [tempo]."
- Lista: "3 erros que [persona] comete ao [ação]."
- POV: "POV: você finalmente [resultado desejado]."
- Curiosidade: "Ninguém fala disso sobre [tema]…"
- Interrupção visual: movimento inesperado, produto em uso extremo, close incomum.
- Prova imediata: "Olha isso" + demonstração nos primeiros 2s.
- Chamada direta: "Se você é [persona], para tudo."
- Depoimento: "Eu não acreditava, mas…"
- Comparação lado a lado.
- Preço/oferta direto (bom para remarketing e público quente).

**Ao entregar hooks, entregue 10+ variações** para o usuário escolher e testar (barato de produzir: mesmo corpo de vídeo, hooks diferentes).

## 4. Estruturas de roteiro

**UGC/depoimento (20–45s):**
1. Hook (0–3s)
2. Problema/contexto pessoal (3–10s)
3. Descoberta do produto (10–15s)
4. Demonstração + benefícios concretos (15–30s)
5. Prova/resultado/objeção quebrada (30–38s)
6. CTA + oferta (38–45s)

**PAS:** Problema → Agitação → Solução.
**AIDA:** Atenção → Interesse → Desejo → Ação.
**Antes/Depois/Ponte:** como é hoje → como poderia ser → o produto é a ponte.
**Demonstração:** hook visual → produto em uso → 3 benefícios → oferta.
**Listicle/razões:** "5 motivos para…", cada motivo com corte rápido.
**Unboxing/primeira impressão.**
**Fundador/história:** autenticidade, bom para marcas com propósito.
**VSL (vídeo de vendas, 2–20 min):** para infoproduto/ticket alto. Hook → promessa → história → mecanismo → prova → oferta → garantia → CTA.

**Formato de entrega de roteiro:**
```
Ângulo: [nome] · Persona: [quem] · Duração: [s] · Formato: 9:16
| Tempo | Cena (visual) | Fala | Texto na tela |
|---|---|---|---|
| 0–3s | ... | ... | ... |
CTA: ...
Variações de hook: 1) ... 2) ... 3) ...
```

## 5. Formatos

| Formato | Forças | Quando usar |
|---|---|---|
| UGC (pessoa real falando) | Autenticidade, CTR | Prospecção, TikTok, Reels |
| Estático (imagem) | Rápido de produzir, ótimo para testar ângulo/oferta | Testes de mensagem, remarketing, oferta |
| Carrossel | Vários produtos/benefícios, storytelling | E-commerce, educação, "antes/depois" em etapas |
| Vídeo de demonstração | Mostra o produto funcionando | Produtos com "efeito uau" |
| Motion/animação | Explicar processo, SaaS | B2B, apps |
| Meme/trend | Alcance, CPM baixo | Marcas com tom descontraído |
| Catálogo/dinâmico | Escala com muitos SKUs | E-commerce, remarketing |
| Estático "nativo" (print de notas, review, tweet) | Parece conteúdo orgânico | Prova social, objeções |

**Specs gerais:** 9:16 (1080×1920) para Stories/Reels/TikTok/Shorts; 4:5 (1080×1350) para o feed; 1:1 como coringa; 16:9 para YouTube. Legenda sempre (a maioria assiste sem som no Meta). Zona segura: deixe ~14% no topo e ~20–35% embaixo livres nos verticais.

## 6. Copy para anúncios

### Meta (texto principal, título, descrição)
- **Texto principal:** as primeiras ~125 caracteres aparecem antes do "ver mais". Coloque o hook/benefício ali.
- Versões curta (1–2 linhas) e longa (storytelling/objeções) — teste as duas.
- **Título:** benefício ou oferta em até ~40 caracteres.
- Emojis com moderação, para escaneabilidade. Quebras de linha.
- Use a **linguagem do cliente** (tirada da pesquisa).
- Ofereça 3–5 variações de cada campo para aproveitar as opções de texto múltiplas.

### Google Pesquisa (RSA)
- 15 títulos (até 30 caracteres): inclua palavra-chave (3–4), benefícios (3–4), prova/diferencial (2–3), oferta/preço (2), CTA (2), marca (1).
- 4 descrições (até 90 caracteres): benefício + prova + CTA.
- **Confira o limite de caracteres** de cada linha ao entregar (conte e indique entre parênteses).

### TikTok
- Texto curto (até ~100 caracteres), tom de conversa, sem cara de anúncio.

### Exemplo de entrega
```
Ângulo 1 — Dor (barulho no home office)
Texto principal: ...
Título: ... (32 car.)
Descrição: ...
```

## 7. Matriz de testes e briefing

**Matriz de testes semanal (exemplo):**
| Conceito/ângulo | Persona | Formato | Hooks | Status | Resultado |
|---|---|---|---|---|---|
| Dor: barulho | Home office | UGC 30s | 3 | Testando | — |
| Prova social | Geral | Estático review | 2 | Vencedor | CPA R$ 42 |

**Briefing para designer/editor/criador UGC:**
```
Objetivo da peça: [prospecção/remarketing] · Plataforma/formato: [9:16, 30s]
Público/persona: ...
Ângulo e mensagem principal (1 frase): ...
Hook (primeiros 3s) — 3 opções: ...
Roteiro/estrutura: ...
Provas a mostrar: ...
Oferta/CTA: ...
Referências (links da Biblioteca de Anúncios/TikTok): ...
O que evitar: [promessas proibidas, termos de política]
Entregáveis: [n° de versões, formatos, com/sem legenda, arquivos brutos]
Prazo: ...
```

## 8. Análise de performance criativa

| Métrica | O que mede | Se estiver baixa |
|---|---|---|
| Hook rate (3s ÷ impressões) | Força do início | Troque hook/primeiro frame |
| Hold rate (ThruPlay ÷ 3s) | Retenção do meio | Ritmo, cortes, conteúdo |
| CTR (link) | Interesse + clareza do CTA | Oferta, CTA, coerência com o público |
| CVR (pós-clique) | Alinhamento anúncio↔página, oferta | Página, promessa, preço |
| CPA/ROAS | Resultado final | Diagnóstico completo |

- Analise **por ângulo/conceito**, não só por anúncio individual (a nomenclatura ajuda).
- Vencedor → **itere**: mesmo ângulo, novos hooks, novos criadores, novos formatos.
- Perdedor com hook rate alto e CVR ruim → problema de promessa/oferta, não de atenção.

## 9. Políticas e cuidados

- **Meta:** não use atributos pessoais ("Você é diabético?", "Está acima do peso?"). Prefira "Para quem busca…". Cuidado com antes/depois, promessas de saúde/renda, "ganhe dinheiro rápido".
- **Categorias especiais** (crédito, emprego, moradia, temas sociais/políticos): segmentação limitada, declaração obrigatória.
- **Saúde/estética, suplementos, finanças, apostas:** regras específicas por plataforma e por legislação brasileira (CONAR, Anvisa, CDC, regras das bets regulamentadas).
- Não prometa resultados garantidos; use prova real e verificável.
- Direitos de uso de imagem, música (use bibliotecas licenciadas da plataforma) e de conteúdo de criadores (contrato com prazo e escopo de uso em anúncio).
